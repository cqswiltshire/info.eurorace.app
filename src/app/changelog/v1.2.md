# Release Notes — V1.2 (2026-10-25)

### ✨ What's New

- **High-Definition Interactive Maps**: Upgraded the interactive journey maps, mini-maps, and checkpoint location pickers with crisp, high-resolution street cartography, making route planning and tracking clearer than ever.

- **Offline & Network Resiliency**: Map displays now feature automatic fallback protection. If external mapping providers experience connectivity issues, EuroRace seamlessly transitions to global OpenStreetMap data so your routes and checkpoint locations remain fully viewable.

- **Enhanced Expense Log & Tables**: Modernised the expense tracking tables with smoother column organisation, faster sorting, and improved responsiveness across desktop and mobile browsers.

### 🐛 Fixes & Performance

- **Platform & Security Enhancements**: Modernised our underlying backend engines and WebAuthn biometric security standards, ensuring faster load times, stronger passkey authentication, and robust data protection.

- **Diagnostic Monitoring**: Enhanced system diagnostics and real-time environment health checks for trip administrators to ensure optimal platform availability.
